MISE EN ROUTE DEPUIS UN TÉLÉPHONE

Fichier du projet : LOrdreCache_3D_Refonte_ANDROID_CI.zip

Option A — déposer les fichiers du projet dans GitHub
1. Crée un dépôt GitHub vide.
2. Extrais le ZIP sur le téléphone avec une application de fichiers qui gère les archives.
3. Téléverse le contenu du dossier du projet dans la racine du dépôt. Conserve notamment .github/workflows/build.yml.
4. Ouvre Actions. Le workflow « Build L'Ordre Caché 3D Android » valide le projet, lance les tests, puis exporte un APK Android de débogage.

Option B — téléverser un seul ZIP (recommandé si tu es uniquement sur téléphone)
1. Crée un dépôt GitHub vide et téléverse LOrdreCache_3D_Refonte_ANDROID_CI.zip à la racine du dépôt.
2. Crée le fichier .github/workflows/build-from-zip.yml dans le dépôt.
3. Copie dedans le contenu du fichier compagnon LOrdreCache_3D_GitHub_Build_From_Zip.yml fourni à côté du ZIP, puis valide le commit.
4. Ouvre Actions et lance « L'Ordre Caché 3D — build Android from ZIP » (ou attends le déclenchement sur push).
5. Dans l'exécution, télécharge l'artefact Android pour obtenir LOrdreCache-3D-debug.apk. L'artefact de validation contient les journaux et le rapport de tests.

L'APK est signé avec une clé de débogage pour installation manuelle. Ce n'est pas une version signée pour Google Play. Le workflow GitHub n'a pas été exécuté depuis cet environnement; si une étape échoue, télécharge les artefacts de journaux dans Actions et partage leur contenu pour diagnostiquer l'erreur exacte.
